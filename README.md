# Monitoring P12
Mobile web monitoring app for P12 containers.

Fitur: KPI, search, filter SPPB/status, detail container, jam register, jam start bongkar, status color, database SQLite, auto refresh after save, health endpoint.

## Local
npm install
npm start

## GitHub
Upload seluruh isi folder ini. Jangan upload node_modules atau p12.db.

## Railway
Connect this GitHub repository to Railway. Railway will use the Dockerfile and PORT.
